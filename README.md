**CampusOS** is a production-style digital operating system for [Adamas University](https://adamasuniversity.ac.in/) / Adamas Knowledge City — campus map, academics, people, clubs, notices, library, AURA assistant, and an admin CMS — designed around:

**SEARCH → UNDERSTAND → NAVIGATE → ACT**

### Why this matters
- Not a generic college CRUD dashboard
- University knowledge layer with source attribution (no invented “official” facts)
- Interactive **OpenStreetMap + Leaflet** campus overlay + topology walking routes
- Mobile + desktop shells, demo student journey, admin-maintainable content

**Repo:** [SK090347/CampusOS-Adamas](https://github.com/SK090347/CampusOS-Adamas)  
**Latest release:** [Releases](https://github.com/SK090347/CampusOS-Adamas/releases)

```text
npm install && npm run db:push && npm run db:seed && npm run dev
```
